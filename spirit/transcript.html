legend

Each row resolves to one symbol. Twenty-eight of the sixty-four possible values are not on this table — if a row lands on one of those, the row is wrong, and you will know at once.

Everything down here is set in capitals. There has never been any lower case at Niwa; the resort has not the patience for it. So if a symbol looks like it could be two different things, it is whichever one is on this table, and it is not the other.
